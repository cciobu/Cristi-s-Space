   • Backend citește și scrie în fișierele HTML
   • Modificările se salvează automat
   • Necesită hosting cu PHP/Node.js

OPȚIUNEA 3: CMS Headless (profesional)
   • Netlify CMS, Strapi, WordPress Headless
   • Interfață admin completă
   • Bază de date pentru conținut
   • Git integration pentru deploy automat

╔══════════════════════════════════════════════════════════════════════╗
║                    STRUCTURA DATELOR PROIECTE                        ║
╚══════════════════════════════════════════════════════════════════════╝

Fiecare proiect are următoarea structură în admin.js:

{
  id: 'canapea-loft',              // Identificator unic
  title: 'Canapea Loft...',        // Titlu complet
  category: 'Mobilier Loft',       // Categorie
  lead: 'Descriere scurtă...',     // Lead paragraph
  description: 'Text lung...',     // Descriere completă
  characteristics: [               // Array caracteristici
    'Dimensiuni: L 200cm...',
    'Material: Oțel...'
  ],
  client: 'Showroom Design',       // Nume client
  date: 'Februarie 2026',          // Data finalizare
  duration: '5 zile',              // Durată execuție
  location: 'Chișinău',            // Locație
  image: 'img/canapea.jpg',        // Cale imagine
  url: 'proiecte/canapea-loft.html' // URL pagină
}
