Scaune Stil Hi-tech

Set de 6 scaune robuste din metal și MDF, perfecte pentru dining, restaurante sau birouri.

Despre proiect

Set de scaune cu design hi-tech care combină durabilitatea metalului cu confortul MDF-ului. Structura din profil pătrat 30x30mm asigură stabilitate maximă, iar șezutul și spătarul din MDF oferă confort.

Caracteristici tehnice

  • Cantitate: Set de 6 scaune
  • Dimensiuni: H 45cm x L 100cm x A 50cm
  • Material cadru: Profil pătrat oțel 30x30mm
  • Material șezut/spătar: MDF 40mm
  • Finisaj metal: Vopsea în pulbere alb
  • Capacitate încărcare: 150 kg/scaun
  • Greutate: 8 kg/scaun

Avantaje

  • Design versatil - se potrivește în orice interior
  • Extrem de durabile - perfecte pentru uz intensiv
  • Stackable - se pot stivui pentru economie de spațiu
  • Ușor de întreținut
  • Rezistente la uzură
