# Cristi's Space - Website pentru Sudură și Construcții Metalice

Website profesional pentru servicii de sudură și construcții metalice în Moldova.

## 📋 Caracteristici

- **Design modern dark theme** cu accenturi gold/orange
- **Responsive** - adaptat pentru mobile, tablet și desktop
- **SEO optimizat** - meta tags, Open Graph, sitemap.xml
- **Formular contact** integrat cu Formspree
- **Cookie consent banner** conform GDPR
- **Google Analytics** ready (necesită configurare)
- **Animații subtile** pentru o experiență premium
- **Galerie portofoliu** cu hover effects

## 🚀 Tehnologii utilizate

- HTML5 semantic
- CSS3 cu variables și animations
- Vanilla JavaScript (fără dependențe)
- Formspree pentru formular contact

## 📁 Structura fișierelor

```
/
├── index.html              # Pagina principală
├── despre.html             # Despre noi
├── servicii.html           # Lista servicii
├── portofoliu.html         # Galerie proiecte
├── contact.html            # Formular contact
├── styles.css              # Stiluri principale
├── app.js                  # JavaScript funcționalități
├── robots.txt              # Configurare crawlere
├── sitemap.xml             # Hartă site pentru SEO
├── .htaccess               # Configurare server Apache
├── 404.html                # Pagină eroare personalizată
├── politica-confidentialitate.html
├── politica-cookies.html
├── termeni-conditii.html
├── /img                    # Imagini proiecte
├── /assets/images          # Imagini SVG decorative
└── logo.PNG                # Logo principal
```

## ⚙️ Configurare necesară

### 1. Google Analytics
În `index.html`, înlocuiește `G-XXXXXXXXXX` cu ID-ul tău real de Google Analytics:
```javascript
gtag('config', 'G-XXXXXXXXXX');
```

### 2. Domeniul website-ului
Actualizează în toate fișierele HTML tag-urile Open Graph:
- Înlocuiește `https://cristispace.com/` cu domeniul tău real

### 3. Formular contact
Formularul folosește Formspree. ID-ul curent: `mvzbqnjz`
- Verifică dacă funcționează sau înregistrează-te pe formspree.io pentru ID nou

### 4. Google Maps (Contact)
Coordonatele actuale sunt pentru Chișinău. Personalizează iframe-ul din `contact.html` cu locația exactă.

## 🎨 Personalizare culori

În `styles.css`, modifică variabilele CSS:
```css
:root {
  --bg: #0a0a0a;           /* Background principal */
  --accent: #e3b35f;       /* Culoare accent gold */
  --accent-2: #ff8c2f;     /* Culoare accent orange */
  --text: #f2f2f2;         /* Text principal */
}
```
